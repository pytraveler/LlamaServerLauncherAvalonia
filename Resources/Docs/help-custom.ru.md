# Пользовательские аргументы

Свободная строка аргументов, которая дописывается к команде `llama-server` после всех параметров, заданных полями на других вкладках. Нужна для флагов, у которых нет своего поля в интерфейсе.

## Как пользоваться

Впишите аргументы так, как вы написали бы их в терминале:

```
--override-tensor "blk\.[0-9]+\.ffn_.*=CPU" --no-kv-offload
```

После ввода нажмите **Enter** или уберите фокус с поля — строка разберётся, и под ней появятся кнопки-тогглы, по одной на каждый аргумент.

## Тогглы

Каждый распознанный аргумент превращается в переключатель:

- **клик** — временно выключить аргумент, не стирая его (выключенные не попадают в команду);
- **правый клик** — удалить аргумент из строки.

Так удобно держать в профиле несколько экспериментальных флагов и включать их по одному, не переписывая строку заново.

## Кнопка «+»

Открывает список аргументов, которые понимает **именно ваш** бинарник: он строится из вывода `llama-server --help`. У каждого аргумента показано описание и допустимые значения — выбранное добавляется в строку. Кнопка появляется только после того, как справка бинарника успешно разобрана.

## Что учитывать

- Аргумент, продублированный здесь и на другой вкладке, попадёт в команду дважды — llama.cpp обычно берёт последнее значение, но лучше этого не делать.
- Кнопка с иконкой очистки стирает всю строку целиком.
- Полная итоговая команда всегда видна в предпросмотре внизу окна — сверяйтесь с ней.
- `--override-tensor` (`-ot`) не имеет отдельного поля и живёт именно здесь; окно **Оптимизировать** при применении результата дописывает его сюда же.
