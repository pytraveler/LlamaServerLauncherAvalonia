# Сценарии

Сценарий — это список профилей, которые запускаются по очереди с заданным интервалом. Удобно, когда нужно последовательно прогнать несколько моделей: сравнить их между собой, прогреть, отдать серию задач разным моделям.

Пока флажок **Включить сценарии** снят, вся полоса сценариев скрыта и на запуск сервера никак не влияет.

## Как собрать сценарий

1. Поставьте **Включить сценарии**.
2. В меню кнопки **Изменить** выберите **Создать сценарий**.
3. Задайте имя.
4. Перенесите нужные профили из левого списка в правый кнопкой `»` — правый список и есть порядок выполнения.
5. Порядок меняется стрелками ▲ ▼ или перетаскиванием.
6. Задайте **интервал** — сколько секунд ждать перед переключением на следующий профиль.
7. Сохраните.

## Параметры

- **Интервал** — пауза между переключениями профилей, в секундах.
- **Автозапуск** — запускать этот сценарий сразу при старте приложения.
- **Клонировать в сценарий** — сделать копию выбранного профиля и добавить её в сценарий, чтобы менять параметры копии, не трогая исходный профиль.

## Запуск

Кнопка **Запустить сценарий** на полосе сценариев запускает выбранный сценарий с первого профиля. Сценарий переключает профили сам; чтобы прервать его, остановите сервер.

> Профили в сценарии запускаются последовательно, а не одновременно. Если нужно несколько моделей в памяти одновременно — запускайте инстансы вручную, каждый со своим портом.
